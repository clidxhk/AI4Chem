# AI4Chem 研习社

课题组 **AI for Chem 研习社** 的资料库：记录一群化学研究者从零开始共同学习 AI 的全过程，并把每周讨论逐步沉淀为一本面向化学研究者的实用学习手册。

## 为什么有这个项目

AI 正在深刻改变化学研究的工作方式：探索空间太大、数据增长太快、重复性工作太多，单靠个人难以应对。AI for Chem 并不是要把化学研究者变成计算机科学家，而是希望把一部分科研问题转化为可以用数据、模型和工具辅助解决的问题——从提出问题、检索知识、整理数据，到建立模型、筛选设计、实验分析与结果解释。

本项目的成员背景各异（小分子合成、近红外探针、纳米生物、聚合物光物理等），多数人没有系统编程基础。我们相信：**不要求一开始就具备很强的计算机或 AI 基础，重要的是持续参与、主动思考和彼此交流。**

## 学习形式

- 第一期持续 **3 个月，共 12 次定时讨论**，每周一次，每次 30–40 分钟；
- 每周围绕一个主题（如第一次的"计算机是什么？"），成员课前各自准备一页 PPT/PDF，鼓励用 AI 辅助完成——**在使用 AI 的过程中学习 AI**；
- 讨论时轮流分享、互相点评对方的优点与不足，并提出下一阶段想学的内容；
- 最后由组织者总结，并共同确定下一周的主题；
- 每次讨论的内容整理后归档到本仓库，最终汇编成学习手册。

## 仓库结构

```
AI4Chem/
├── 背景/       # 研习社的计划、招募说明等背景材料
├── 01-第一次/  # 第一次讨论：相互认识与需求摸底（PPT、录音转写记录）
├── 02-第二次/  # 第二次讨论：计算机的本质（议题说明、PPT、会议记录、五人笔记、对比分析、参考资料）
├── 03-第三次/  # 第三次讨论：数据和信息（议题说明、PPT、五人笔记）
├── 04-第四次/  # 第四次讨论：机器学习与神经网络（讨论记录、五人笔记、视频文字稿）
├── 05-第五次/  # 第五次讨论：从 ChatBot 到 Agent（议题、PPT、录音转写、五人笔记、对比分析、视频字幕）
├── 手册/       # 最终成果：由讨论记录整理成的讲义章节
└── AGENTS.md   # 协作与 Git 提交规范
```

每次讨论一个目录（数字前缀＋中文序号命名，如 `01-第一次/`），内存放当次 PPT、录音转写记录、各成员的课前笔记（保留原文件名）以及整理后的对比分析。

## 一、议题说明

### 本周主题：数据和信息——AI 的燃料从哪里来？

**核心问题：你的实验记录本，在计算机眼里是什么？**

### 为什么现在讨论这个

第二次讨论我们弄清了计算机本身：它只会按规则处理 0 和 1，并不"理解"什么。那么自然有一个问题：我们的波长、产率、谱图、分子结构……这些五花八门的科研数据，是怎么变成 0 和 1 的？反过来，一堆 0 和 1 又怎么变成"信息"甚至"知识"？

这是机器学习的前置课：**数据是 AI 的燃料**。先把燃料看清楚，第四次讨论"机器学习"（机器怎么从数据里学规律）才有抓手。

### 本周的三个小目标

1. 分清**数据、信息、知识**——并能在自己的科研材料里各找一个例子；
2. 理解"一切皆 0/1"：文字、数字、图像在计算机里如何表示（呼应第二次讨论的 bit 与编码）；
3. 盘点自己科研数据的**类型**和**质量**，建立"什么才算好数据"的判断——这是以后做性质预测数据集的基本功。

### 为什么这对我们重要（第一次讨论的伏笔）

第一次讨论分析 AIE 分子库时我们说过：**预测效果的上限是数据集质量决定的**——那个库只包含发射/波长信息，数据来自不同文献、标准不一，所以预测效果偏低。数据质量不是 IT 问题，是科学问题。

### 本周不展开的内容

特征、标签、模型、机器学习的概念——留给第四次；SMILES 等分子表示方法的细节——留给后面的分子表示专题。本周第 5 问只会"预告式"地碰一下机器学习。

## 三、讲义五问

每人回答以下五问，做一页 PPT/PDF，分享不超过 3 分钟：

1. **什么是数据？什么是信息？** 它们是什么关系？从你自己的实验记录或一篇文献里，各找一个"数据"和"信息"的例子。
   （提示：一串数字 vs "产率 72.3%"；原始谱图信号 vs "这个分子在 802 nm 处有吸收"。还可以再想一步：什么算知识？）

2. **计算机里只有 0 和 1，文字、数字、图片、分子结构分别是怎么被表示的？**
   （呼应第二次讨论的 bit 与编码。可以大胆猜：分子结构能不能也变成 0 和 1？不确定就去问 AI。）

3. **盘点你的科研数据：哪些是"整理好的"，哪些是"沉睡的"？**
   哪些是结构化的表格（Excel/CSV：数值、类别），哪些是非结构化的文本、图像、谱图原始文件、分子结构？哪些能直接拿来做分析，哪些需要先"翻译"成计算机可用的形式？

4. **什么样的数据才算"好数据"？**
   准确性、一致性、完整性、可追溯……结合你的领域说说：文献里的数据为什么经常"不好用"？数据"多"和"好"哪个更重要？

5. **（预告）你觉得计算机能从数据里"自己学出规律"吗？**
   人总结构效关系靠专业直觉和积累，机器要"学"的话，至少需要什么条件？（开放题，没有标准答案——第四次讨论从这里开始。）

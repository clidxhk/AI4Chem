## 一、议题说明

### 本周主题：机器学习——AI 的发动机怎么转？

**核心问题：模型到底是"背下了答案"，还是"学会了规律"？**

### 三周复盘：我们从哪里走到了这里

- **第一次（需求摸底）**：拿到了 AIE 分子库这个真实痛点——预测效果的上限，是数据集质量决定的；
- **第二次（计算机的本质）**：计算机只会按规则处理 0 和 1，它自己并不"理解"任何东西；
- **第三次（数据和信息）**：数据是 AI 的燃料——一切都要变成 0/1，而"什么算好数据"本身是门学问。

三周下来，燃料的问题看清楚了。可燃料怎么变成动力？**机器学习就是那台发动机**：它不靠人写死每一条规则，而是从数据里自己"学"出规律。这次讨论把这台发动机拆开看一眼——这也是动手项目开始前最后一节概念课。

### 本周目标

1. 理清**人工智能 ⊃ 机器学习 ⊃ 深度学习**的包含关系，知道"神经网络"站在哪一层——以后看到 AI 新闻能自己定位；
2. 会给任务"选范式"：监督还是非监督？回归还是分类？能在自己的科研问题里指出**特征（X）**和**标签（y）**；
3. 建立"**模型 = 从数据里学出来的函数**"的直觉，认识三个最基础的模型家族：线性模型、树模型、基于距离的模型；
4. 掌握评估模型的基本动作：训练集/测试集划分、过拟合、常用指标——并且想清楚：对化学研究来说，**"可解释"为什么和"准确"一样重要**。

### 为什么这对我们重要

下一次讨论开始，我们就要动手做 **LogP 性质预测**了。到时候你会遇到本周每一个概念的实物：由 SMILES 算出的分子描述符是**特征**，LogP 实验值是**标签**，任务类型是**回归**，模型可能是一棵**决策树**，评价指标用 RMSE，而"这个模型凭什么这么预测"就是**解释**问题。这周把概念铺好，下周写代码时就不会一头雾水。

### 本周不展开的内容

- 神经网络内部怎么算（激活函数、反向传播、梯度下降）——留给后面的深度学习专题；
- 强化学习——第三种学习范式，本周只留个名字，后面讲到大模型时再回来；
- 交叉验证、超参数调优这些进阶技巧——在练手项目里边做边学；
- 分子描述符、分子指纹怎么构造——第五次讲。

## 二、讲义五问

> 说明：每问的两个小问可以合并回答，不要求分开作答；时间不够时优先讲自己领域的例子。分享不超过 3 分钟。

### 1. 层级

- 人工智能、机器学习、神经网络、深度学习，这四个词是什么关系？谁能包含谁？试着画一张"套娃图"。
- 挑一个你听说过的 AI 应用（AlphaFold、ChatGPT、谱图识别……），说说它属于哪一层，为什么。

### 2. 流派

- 符号主义和联结主义分别是怎么"实现智能"的？各举一个代表方法，说说两者的优缺点。
- 在化学里找一找：哪些工具更像"符号主义"（规则库、专家系统、反应模板），哪些更像"联结主义"（神经网络预测性质/谱图/合成路线）？

### 3. 范式

- 监督学习和非监督学习的本质区别是什么？"无监督"的机器到底在学什么？
- 回归和分类的区别是什么？从你的科研里找一个适合监督学习的问题：它的特征是什么？标签是什么？属于回归还是分类？

### 4. 模型

- 到底什么是"模型"？它和物理化学里的公式、程序里的 if-else 规则有什么不一样？"训练"完成之后，模型以什么形式存在？
- 线性模型、决策树、K 近邻（基于距离的模型）分别是怎么做出预测的？凭直觉说说：哪类最好解释？哪类最容易"背题"（过拟合）？

### 5. 评估与解释

- 怎么判断一个模型"学得好不好"？为什么必须留一部分数据不参加训练（训练集/测试集划分）？"过拟合"是什么现象？
- 一个模型哪怕预测得再准，如果说不清"为什么"，你敢把它用在科研判断里吗？（开放题）对我们化学人来说，模型解释意味着什么？

## 三、动手实践（课前完成）：走进 GitHub——注册账号、装好工具

为什么练这个？我们共学班的资料库本身就托管在 GitHub 上（<https://github.com/clidxhk/AI4Chem>），第五次起的练手项目，代码和数据也都会放上去。对科研人来说，GitHub 就像"带完整修改历史的实验记录本"：每一次改动都有记录、能回退、能协作——这是 AI4Chem 的基本功。（上周装好的 Anaconda 和 VS Code 先歇一周，第五次做 LogP 项目时正式开工。）

### 基础实践（人人完成）

1. **注册 GitHub 账号**：<https://github.com/signup>。用户名建议用易读的拼音或英文名——它以后会出现在你的主页网址里，也方便同学找到你；记得完成邮箱验证。
2. **安装 Git**（Windows）：<https://git-scm.com/download/win>，一路默认安装即可；若安装选项里能选默认编辑器，顺手选 **VS Code**。
3. **安装 GitHub Desktop**（图形界面版，不必背命令行）：<https://desktop.github.com/>，装好后用它登录 GitHub 账号。
4. 验收三步：
   - 打开命令行，`git --version` 有输出；
   - GitHub Desktop 显示已登录账号；
   - 用 GitHub Desktop 克隆共学班仓库：`File → Clone Repository → URL`，填 `https://github.com/clidxhk/AI4Chem.git`，克隆完成后能看到 `AGENTS.md` 和各次讨论的目录。
5. 思考题（课上要用）：用任意编辑器打开仓库里的 `第三次/第三次讨论-议题说明与讲义五问.md`，随手改动一个字，再看 GitHub Desktop 左侧发生了什么？**Commit** 和 **Push** 两个按钮各是什么意思？
6. 卡点预警：国内网络访问 GitHub 时快时慢，注册、克隆若超时，换个时段或网络再试；报错 `unable to access` 多半是网络问题，不是你操作错了。
7. 把验收截图带来（卡在哪一步也照实记录，课上一起排错）。

### 高阶实践（选做）：用 GitHub Pages 搭一个自己的学术主页

1. 在 GitHub 网页上新建一个仓库，名字必须严格是 **`<你的用户名>.github.io`**（如用户名是 `zhangsan`，仓库名就是 `zhangsan.github.io`）；建仓时勾选"Add a README file"。
2. 在仓库页面点 `Add file → Create new file`，文件名输入 `index.html`，粘贴这段最小可用代码，点 `Commit changes` 提交：

   ```html
   <!DOCTYPE html>
   <html lang="zh">
   <head><meta charset="utf-8"><title>我的学术主页</title></head>
   <body>
     <h1>你的名字</h1>
     <p>单位 ／ 研究方向：AI 辅助的××研究</p>
     <p>联系方式：you@example.com</p>
   </body>
   </html>
   ```

3. 等一两分钟，浏览器打开 `https://<你的用户名>.github.io`，看到页面即成功——**网页本质上就是一个文本文件**，正好呼应第二次讨论讲的编码、第三次讲的"一切皆 0/1"。
4. 主页放什么：一段自我介绍＋研究方向、论文/成果列表（可挂 Google Scholar 链接）、联系方式。以后投稿、求职、认识同行，这就是递出去的"电子名片"。
5. 想做漂亮些可以用现成模板（如 Hugo Academic、al-folio），但建议先跑通这个基础版，模板留到熟悉 Git 之后再玩。
6. 把主页网址或截图带来课上展示。

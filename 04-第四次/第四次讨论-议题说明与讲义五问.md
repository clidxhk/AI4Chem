## 一、议题说明

### 本周主题：机器学习与神经网络

**核心问题：模型是"背答案"，还是"学规律"？**

### 核心目标

理清人工智能、机器学习、神经网络、深度学习这几个词的关系；认识几个最简单的模型；知道怎么初步判断一个模型好不好。概念先混个脸熟，第五次起结合 LogP 预测项目的真实案例再深入。

### 为什么现在讨论这个

前三次我们弄清了两件事：计算机只会按规则处理 0 和 1（第二次），数据是 AI 的燃料（第三次）。燃料有了，这次看发动机——机器怎么从数据里学出规律。这也是第五次动手项目开始前最后一节概念课。

### 本周不展开的内容

模型内部怎么算（线性方程怎么拟合、树怎么长、神经网络怎么反向传播）、训练/测试划分与评估指标的操作细节——留给第五次起的 LogP 项目边做边讲；强化学习只留个名字；分子描述符怎么构造，第五次讲。

## 二、讲义五问

> 说明：每问的两个小问可以合并回答，不要求分开作答；时间不够时优先讲自己领域的例子。分享不超过 3 分钟。

### 1. 层级

- 人工智能、机器学习、神经网络、深度学习，这四个词是什么关系？谁能包含谁？
- 挑一个你听说过的 AI 应用（AlphaFold、ChatGPT、谱图识别……），说说它属于哪一层，为什么？

### 2. 流派

- 符号主义和联结主义分别是怎么"实现智能"的？各举一个代表方法，说说两者的优缺点。
- 在化学和生物研究里找一找：哪些工具更像"符号主义"，哪些更像"联结主义"？

### 3. 类别

- 监督学习和非监督学习的区别是什么？
- 回归和分类的区别是什么？结合你的研究里找一个适合监督学习的问题：它的特征是什么？标签是什么？属于回归还是分类？

### 4. 模型

- 什么是"模型"？它和物理化学里的公式有什么不一样？
- 认识三个简单模型：线性模型、决策树、K 近邻，谈谈你的理解。

### 5. 评估与解释

- 怎么判断一个模型"学得好不好"？
- 一个模型哪怕预测得再准，如果说不清"为什么"，你敢把它用在科研判断里吗？

### 提交笔记怎么做（第一次做，照着走）

0. 先把你的 GitHub 用户名发给组织者，接受仓库协作者（collaborator）邀请——没有写权限是推不上去的；
1. 打开 GitHub Desktop → `File → Clone Repository → URL`，填 `https://github.com/clidxhk/AI4Chem.git`，选个本地文件夹克隆下来；
2. 打开克隆下来的文件夹，把你的笔记复制进 `04-第四次/`，按上面的规则命名；
3. 回到 GitHub Desktop：左侧会看到新文件，Summary 随便写一句（如"张三提交笔记"），点 **Commit to master**；
4. 再点顶部 **Push origin**——刷新 GitHub 网页，能看到你的文件就成功了。

   备用通道：实在装不好软件，可在仓库网页上点 `Add file → Upload files`，拖入文件后点 Commit changes，效果一样。

### 卡点预警

国内网络访问 GitHub 时快时慢，注册、克隆若超时，换个时段或网络再试；报错多半是网络问题，不是你操作错了。卡住了把界面截图带来，课上一起排错。

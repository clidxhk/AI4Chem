## 一、议题说明

### 本周主题：机器学习——AI 的发动机怎么转？

**核心问题：模型到底是"背下了答案"，还是"学会了规律"？**

### 三周复盘：我们从哪里走到了这里

- **第一次（需求摸底）**：拿到了 AIE 分子库这个真实痛点——预测效果的上限，是数据集质量决定的；
- **第二次（计算机的本质）**：计算机只会按规则处理 0 和 1，它自己并不"理解"任何东西；
- **第三次（数据和信息）**：数据是 AI 的燃料——一切都要变成 0/1，而"什么算好数据"本身是门学问。

三周下来，燃料的问题看清楚了。可燃料怎么变成动力？**机器学习就是那台发动机**：它不靠人写死每一条规则，而是从数据里自己"学"出规律。这次讨论把这台发动机拆开看一眼——这也是动手项目开始前最后一节概念课。

### 本周目标（概念入门版）

1. 说得清**人工智能 ⊃ 机器学习 ⊃ 深度学习**的套娃关系，知道"神经网络"站在哪一层；
2. 认识两组最基本的"分法"：**监督/非监督**、**回归/分类**，能给自己科研里的一个问题归归类；
3. 见识三个最基础的模型家族（线性模型、树模型、按距离找答案的模型），建立"模型 = 从数据里学出来的函数"的第一印象；
4. 带走一个好问题：怎么分辨模型是"学会了"还是"背题了"？

本周只求概念"混个脸熟"——每个概念都会在第五次起的 LogP 项目里结合真实案例再见面、再细抠。

### 为什么这对我们重要

下一次讨论开始，我们就要动手做 **LogP 性质预测**了。今天认识的每个名词，到时都会变成看得见摸得着的实物：输入给模型的是分子的**特征**，要预测的 LogP 实验值是**标签**，任务类型是**回归**……所以本周的任务不是吃透原理，而是**把名词和自己的科研问题对上号**——名字先叫熟，等真实数据到手边时才不会一头雾水。

### 本周不展开的内容（后面结合实际案例再讲）

- 各类模型内部到底怎么算（线性方程怎么拟合、树怎么长、神经网络怎么反向传播）——第五次起的 LogP 项目和深度学习专题里，用真实数据边做边讲；
- 训练集/测试集划分、过拟合、评估指标（RMSE、准确率）的操作细节——同样留给练手项目，本周只建立"背题 vs 学会"的直觉；
- 强化学习——第三种学习范式，本周只留个名字，后面讲到大模型时再回来；
- 分子描述符、分子指纹怎么构造——第五次讲。

## 二、讲义五问

> 说明：每问的两个小问可以合并回答，不要求分开作答；时间不够时优先讲自己领域的例子。分享不超过 3 分钟。

### 1. 层级

- 人工智能、机器学习、神经网络、深度学习，这四个词是什么关系？谁能包含谁？试着画一张"套娃图"。
- 挑一个你听说过的 AI 应用（AlphaFold、ChatGPT、谱图识别……），说说它属于哪一层。

### 2. 流派

- 让机器"聪明"起来，历史上有两条思路：一条是**人把规则写给它**（符号主义），一条是**让它自己从数据里学**（联结主义）。用你自己的话说说这两条思路的区别。
- 在化学里找一找：你用过或听过的工具里，哪些更像前者（反应规则模板、专家系统），哪些更像后者（神经网络预测性质/谱图）？

### 3. 范式

- 监督学习和非监督学习的区别是什么？（提示：区别就在有没有"标准答案"。至于"无监督"的机器到底在学什么，也是个好问题。）
- 回归和分类的区别是什么？从你的科研里找一个适合机器学习的问题：它想预测什么？属于回归还是分类？（行话：输入叫"特征"，标准答案叫"标签"，能指出来更好。）

### 4. 模型

- 什么叫"模型"？它和我们写的物理化学公式、程序里的 if-else 规则有什么不一样？
- 只求"认识"三个最基础的模型家族：线性模型、决策树、K 近邻（按"距离"找答案的模型）。各用一句话说说你的理解，或画个小示意图——哪个让你觉得最好懂？

### 5. 评估

- 一个学生靠"刷题背答案"，考试换道题就不会了。你觉得模型会不会也这样？怎么检查它是"学会了"还是"背题了"？
- （开放题）一个模型哪怕预测得再准，如果说不清"为什么"，你敢把它用在科研判断里吗？

## 三、动手实践（课前完成）：迈出第一步——注册 GitHub

为什么认识它？我们共学班的资料库就托管在 GitHub 上（<https://github.com/clidxhk/AI4Chem>），以后练手项目的代码和数据也会放上去。GitHub 对科研人就像"带完整修改历史的实验记录本"——这个比喻本周先记住就行，**克隆、提交这些动作后面有专题手把手教，本周只完成三件小事**。（上周装好的 Anaconda 和 VS Code 先歇一周，第五次做 LogP 项目时正式开工。）

### 基础实践（人人完成，约 10 分钟）

1. **注册 GitHub 账号**：<https://github.com/signup>。用户名建议用易读的拼音或英文名——它以后会出现在你的主页网址里，也方便同学找到你；记得完成邮箱验证。
2. **安装 GitHub Desktop**（图形界面版）：<https://desktop.github.com/>，装好后用它登录 GitHub 账号。不用单独装 Git 命令行工具——Desktop 已经自带，等后面的专题需要时再装不迟。
3. **给共学班仓库点一个 Star**：浏览器打开 <https://github.com/clidxhk/AI4Chem>，点右上角的 ★ Star。它就会出现在你的 GitHub 首页里，以后随时找得到。
4. 验收：截图 GitHub Desktop 登录成功后的界面（能看到自己的账号名即可），带来课上。
5. 卡点预警：国内网络访问 GitHub 时快时慢，注册若超时，换个时段或网络再试；报错多半是网络问题，不是你操作错了。卡住了别慌，把卡住的界面照实截图带来，课上一起解决。

### 高阶实践（选做，同样零代码）：把 GitHub 个人页变成你的"学术名片"

1. 登录 GitHub 网页版，点右上角头像 → `Your profile`；
2. 上传一张头像（微信/QQ 头像就行），**Name** 改成真名或常用名，**Bio** 里写一句研究方向（如"有机方法学｜对 AI 辅助催化剂设计感兴趣"）；
3. （课上一起做）找到同学的账号，点 **Follow** 互相关注；
4. 这张"名片"以后跟着你所有的代码和项目走——投稿、求职、认识同行都用得上。

> **课上现场演示预告**：组织者会当众做两个动作——用 GitHub Desktop 把共学班仓库**克隆**到本地（看看"把资料库搬回家"长什么样），以及用 GitHub Pages **建一个学术主页**（几行 HTML 就能上线）。主页搭建不用急着课前做，后面有专门的一课手把手带大家完成。

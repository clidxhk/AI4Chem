## 一、议题说明

### 本周主题：数据和信息——AI 的燃料从哪里来？

**核心问题：你的实验记录本，在计算机眼里是什么？**

### 为什么现在讨论这个

第二次讨论我们弄清了计算机本身：它只会按规则处理 0 和 1，并不"理解"什么。那么自然有一个问题：我们的波长、产率、谱图、分子结构……这些五花八门的科研数据，是怎么变成 0 和 1 的？反过来，一堆 0 和 1 又怎么变成"信息"甚至"知识"？

这是机器学习的前置课：**数据是 AI 的燃料**。先把燃料看清楚，第四次讨论"机器学习"（机器怎么从数据里学规律）才有抓手。

### 本周目标

1. 分清**数据、信息、知识**——并能在自己的科研材料里各找一个例子；
2. 理解"一切皆 0/1"：文字、数字、图像在计算机里如何表示（呼应第二次讨论的 bit 与编码）；
3. 建立"什么才算好数据"的判断——这是以后做性质预测数据集的基本功。

### 为什么这对我们重要（第一次讨论的伏笔）

第一次讨论分析 AIE 分子库时我们说过：**预测效果的上限是数据集质量决定的**——那个库只包含发射/波长信息，数据来自不同文献、标准不一，所以预测效果偏低。数据质量不是 IT 问题，是科学问题。

### 本周不展开的内容

特征、标签、模型、机器学习的概念——留给第四次；SMILES 等分子表示方法的细节——留给后面的分子表示专题。本周第 5 问只会"预告式"地碰一下机器学习。

## 二、讲义五问

> 说明：每问的两个小问可以合并回答，不要求分开作答；时间不够时优先讲自己领域的例子。分享不超过 3 分钟。

### 1. 概念

- 什么是数据？什么是信息？它们是什么关系？（再想一步：什么算知识？）
- 从你自己的实验记录或一篇文献里，各找一个"数据"和"信息"的例子。

### 2. 表示

- 数据的类型有哪些？
- 计算机里只有 0 和 1，文字、数字、图片、分子结构分别是怎么被表示的？

### 3. 结构化与非结构化

- 结构化数据与非结构化数据有什么区别？
- 盘点你的科研数据：哪些是结构化的数据，哪些是非结构化的数据？

### 4. 标准

- 什么样的数据才算"好数据"？准确性、一致性、完整性、可追溯……
- 数据"多"和"好"哪个更重要？

### 5. 开放性问题

- 结合你的领域说说：文献里的数据为什么经常"不好用"？
- 机器要"学出规律"，所提供的数据至少需要什么条件？（开放题，没有标准答案——第四次讨论从这里开始。）

## 三、动手实践（课前完成）：安装 Anaconda 和 VS Code

1. 下载并安装 **Anaconda**：清华镜像 <https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/>，选择最新的 `Windows-x86_64` 安装包（完整版约 1 GB，请耐心下载）；
2. 安装 **VS Code**：<https://code.visualstudio.com/>，装好后打开扩展商店（`Ctrl+Shift+X`），搜索并安装微软官方的 **Python** 插件；
3. 验收三步：
   - 打开 Anaconda Prompt，`conda --version` 和 `python --version` 各有输出；
   - 新建环境并激活：`conda create -n ai4chem python=3.11` → `conda activate ai4chem`；
   - 在 VS Code 新建 `hello.py`，输入 `print("hello ai4chem")`，在窗口右下角（或顶部）把解释器切换为 `ai4chem`，运行出结果。
4. 常见卡点预警：VS Code 默认解释器往往不是刚建的 conda 环境，需要手动切换一次；安装路径建议保持默认，避免中文或带空格的路径。
5. 把验收截图和遇到的报错一起带来（没装成功也如实记录卡在哪一步，课上一起排错）。
